# Use of the RightLayout name

RightLayout is Apache-2.0: the code is free to use, fork, modify, and ship.
What the license does not grant is the project name (Apache License,
section 6). This page explains what that means in practice. Forks are
welcome; the only aim is that users can tell builds apart.

## You can, without asking

- Fork the code and change it however you like.
- Keep the fork's repository name as `RightLayout` on GitHub.
- Ship your own builds, signed with your own key, as long as the app name,
  release page, or listing makes clear it is your build — for example
  "RightLayout (yourname build)" or a name of your own.
- Say your project is **based on RightLayout** or **a fork of RightLayout**.

## Please ask first

- Publishing a build as plain "RightLayout" in an app store or other
  distribution channel, where it reads as the official app.
- Using the RightLayout icon or name in a way that presents a build as
  official.
- Registering domains or social-media handles that read as official
  project channels.

## Why

A user who hits a bug needs to know whose build they are running, and
whose key signed it.

## How to ask

Open an issue on this repository or email alex@alexchernysh.com.
When confusion is unlikely, the default answer is yes.
